SIMON GAME
simon is a classic electronic memory game where the device plays an expanding sequence of colored lights and tones and the player must repeat them; it was invented in 1978 and remains a compact, well‑studied test of short‑term sequential memory.
Core idea: The device shows a sequence of lights + tones; each successful repeat extends the sequence by one random element; a mistake ends the run. 
Standard mode (Game 1): Watch Simon’s sequence and repeat exactly. Difficulty levels set target lengths (e.g., 8, 14, 20, 31). 

Player Says (Game 2): Player creates the sequence after Simon’s first tone. 

Choose Your Color (Game 3): Multiplayer elimination where each player is responsible for one or more colors



ZACTIVITY
ZACTIVITY is a simple color generator that demonstrates an effective use of HTML, CSS, and JavaScript. It generates a random color when you click the Generate button and displays the color’s numerical values such as HEX and RGB.
